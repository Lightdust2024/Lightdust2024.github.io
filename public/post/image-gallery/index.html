图片画廊

stack主题的官方文档，使用 Markdown 创建漂亮的交互式图片画廊

2023年8月26日星期六 阅读时长: 1 分钟

Hugo Stack 主题支持使用 Markdown 创建交互式图片画廊。它由 PhotoSwipe 驱动，其语法灵感来自 Typlog。

要使用此功能，图片必须与 Markdown 文件位于同一目录中，因为它需要借助 Hugo 的页面包（page bundle）功能来读取图片尺寸。不支持外部图片。
